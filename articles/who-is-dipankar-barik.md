## Why the MERN stack?

The MERN stack brings together technologies that let me work across a complete web product:

- **MongoDB** for document-oriented data storage and flexible data models.
- **Express.js** for building clear, maintainable APIs and server-side middleware.
- **React** for interactive interfaces organized around reusable components.
- **Node.js** for JavaScript-powered server applications and tooling.

I enjoy connecting these layers: shaping a data model that supports the product, designing APIs that are predictable to consume, and building React interfaces that communicate loading, success, and error states clearly. The stack is a set of tools, not a shortcut around careful engineering.

I want to keep growing as an engineer who can move comfortably between frontend experience and backend implementation. My focus is on readable code, practical architecture, accessible interfaces, and steady improvement through feedback.
